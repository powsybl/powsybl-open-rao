# Glossary

| Term                                                              | Acronym | Definition                                                                                                                                                                                                                   |
|-------------------------------------------------------------------|---------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Open Remedial Actions Optimizer                                   | OpenRAO | Open-source project aimed at providing an efficient solution for electrical power systems’ Coordinated Capacity Calculation, Local Security Analysis and Coordinated Security Analysis                                      |
| Calculation with Scalable and Transparent Optimizer               | CASTOR  | Non-costly remedial actions optimizer                                                                                                                                                                                        |
| Transmission System Operator                                      | TSO     | Entity entrusted with transporting energy in the form of natural gas or electrical power on a national or regional level, using fixed infrastructure.                                                                        |
| Remedial Action Optimization                                      | RAO     | Provides an optimal selection of remedial actions to handle overloads on network elements (CNECs) in contingency situations (outages)                                                                                        |
| Individual Grid Model                                             | IGM     | The grid model of a specific TSO                                                                                                                                                                                             |
| Common Grid Model                                                 | CGM     | The "merged" grid models of multiple TSOs into one grid model                                                                                                                                                                |
| Critical Branch                                                   | CB      | An important network element with regards to grid security and market exchanges                                                                                                                                              |
| Critical Outage                                                   | CO      | A probable event consisting of the loss of 1 or more elements on the grid. Also refers to a contingency.                                                                                                                     |
| Critical Branch - Critical Outage                                 | CBCO    | Critical Branch monitored after a Critical Outage (same as CNEC)                                                                                                                                                             |
| Critical Network Element                                          | CNE     | A monitored Critical Network Element (can be a CB)                                                                                                                                                                           |
| Critical Network Element & Contingency                            | CNEC    | Critical Network Element monitored after a critical Contingency (can be a CBCO)                                                                                                                                              |
| Monitored Network Element & Contingency                           | MNEC    | Network element monitored during the RAO without being optimized (used to ensure that remedial actions do not create new overloads on other elements)                                                                        |
| Contingencies, Remedial Actions and other Constraints             | CRAC    | File model containing COs, CNECs, and remedial actions                                                                                                                                                                       |
| Phase Shift Transformer                                           | PST     | Transformer that can be used to control the power flow on lines                                                                                                                                                              |
| Remedial Action                                                   | RA      | Action on the network performed to reduce constraints on CNECs                                                                                                                                                               |
| Linear Remedial Action                                            | LRA     | Type of remedial action considered to have a linear effect on flows (e.g., changing the angle of a PST, the set-point of an HVDC, the set-point of a generation unit)                                                       |
| Preventive Remedial Action                                        | PRA     | Remedial action performed on the N-state (i.e., before any contingency)                                                                                                                                                      |
| Automatic Remedial Action                                         | ARA     | Remedial action triggered automatically without any human intervention after a contingency (also called SPS)                                                                                                                 |
| Special Protection Scheme                                         | SPS     | Automatic remedial action triggered without human intervention after a contingency (same as ARA)                                                                                                                              |
| Curative Remedial Action                                          | CRA     | Remedial action performed by human activation after a contingency                                                                                                                                                            |
| Remaining Available Margin                                        | RAM     | For a CNEC, the remaining flow margin between its actual flow and the maximum flow allowed                                                                                                                                   |
| Net Transfer Capacity                                             | NTC     | Capacity calculation method providing a unique capacity value per frontier by disregarding other bidding zones' electrical impact                                                                                            |
| Flow-Based                                                        | FB      | Capacity calculation method providing a capacity value for each CNEC by taking into account all bidding zones' electrical impact                                                                                             |
| Generation and Load Shift Keys                                    | GLSK    | Provides net position variation mapping rules to a network's generators and loads                                                                                                                                            |
| Generation Shift Key                                              | GSK     | Translates a variation of net position of a bidding zone into a variation of generation injection (see also GLSK)                                                                                                            |
| Power Transfer Distribution Factors                               | PTDF    | Indicates the incremental change in real power that occurs on transmission lines due to real power transfers between two regions                                                                                             |
| Phase Shifter Distribution Factor                                 | PSDF    | Sensitivity factor measuring the impact of a phase shift transformer (PST) tap or angle variation on the flow of a network element                                                                                           |
| Regional Coordination Center                                      | RCC     | Performs tasks of regional relevance in the system operation region (SOR) where they are established, such as, in particular: coordinated capacity calculation, coordinated security analysis and creating common grid models |
| Regional Security Coordinators                                    | RSC     | Evolved into Regional Coordination Centers (RCCs) in July 2022                                                                                                                                                               |
| System Operation Region                                           | SOR     | Geographic area defined by ENTSO-E for regional coordination and operation of electricity transmission systems                                                                                                               |
| Coordinated Security Analysis                                     | CSA     | Regional operational security analysis to identify network constraints and coordinate remedial actions                                                                                                                       |
| Coordinated Capacity Calculation                                  | CCC     | Regional calculation of cross-zonal capacities across a Capacity Calculation Region                                                                                                                                          |
| Capacity Calculation Region                                       | CCR     | Geographic area in which coordinated capacity calculation is applied pursuant to CACM regulations                                                                                                                            |
| Capacity Allocation & Congestion Management                       | CACM    | European regulation and methods for calculating how much capacity market participants can use on cross-border lines without endangering system security                                                                       |
| Clean Energy Package                                              | CEP     | European Union legislative framework for energy, including the 70% minimum capacity margin rule on interconnectors                                                                                                           |
| European Network of Transmission System Operators for Electricity | ENTSO-E | Association for the cooperation of European transmission system operators (TSOs)                                                                                                                                             |
| European Union Agency for the Cooperation of Energy Regulators    | ACER    | Agency of the European Union responsible for coordinating national energy regulators                                                                                                                                        |
| National Regulatory Authority                                     | NRA     | Public authority designated by a Member State to regulate energy markets at national level                                                                                                                                   |
| Network Codes                                                     | NC      | Common European rules for electricity networks (e.g., CACM, SO GL) and associated ENTSO-E CIM profile format                                                                                                                  |
| Central South Europe                                              | CSE     | Capacity Calculation Region (CCR) covering Northern Italy and adjacent borders (Italy North - IN)                                                                                                                                  |
| South West Europe                                                 | SWE     | Capacity Calculation Region (CCR) covering France, Spain, and Portugal                                                                                                                                                       |
| Core                                                              | CORE    | Capacity Calculation Region (CCR) covering central and western continental Europe                                                                                                                                            |
| High Voltage Direct Current                                       | HVDC    | Electric power transmission system using direct current for bulk transmission of electricity                                                                                                                                 |
| Multi-Terminal High Voltage Direct Current                         | MTHVDC  | High Voltage Direct Current system connecting more than two converter stations                                                                                                                                               |
| Load-Frequency Control                                            | LFC     | Operational process maintaining grid frequency and power balance within designated control areas and blocks                                                                                                                  |
| Redispatching                                                     | RD      | Measure altering generation and/or load patterns to change physical flows and relieve network congestion                                                                                                                     |
| Flow Reliability Margin                                           | FRM     | Margin accounting for uncertainties in capacity calculation and operational security assessments                                                                                                                             |
| Temporary Admissible Transmission Loading                         | TATL    | Admissible load on a CNEC after a contingency in a restricted time frame                                                                                                                                                     |
| Permanent Admissible Transmission Loading                         | PATL    | Admissible load on a CNEC (before or after a contingency) in a steady state                                                                                                                                                  |
| Minimum Margin                                                    | MM      | The minimum flow margin among all CNECs                                                                                                                                                                                      |
| Minimum Relative Margin                                           | MRM     | Minimum Margin (MM) divided by the sum of PTDFs (sum of zone-to-zone PTDFs on the given CNEC)                                                                                                                                |
| iTesla Internal Data Model                                        | IIDM    | The PowSyBl native grid format (see on [PowSyBl](inv:powsyblcore:*:*#grid_model/index))                                                                                                                                      |
| XML iTesla Internal Data Model                                    | XIIDM   | XML serialization format of the PowSyBl IIDM grid model                                                                                                                                                                      |
| JSON iTesla Internal Data Model                                   | JIIDM   | JSON serialization format of the PowSyBl IIDM grid model                                                                                                                                                                     |
| Common Information Model                                          | CIM     | File format standards developed by ENTSO-E in line with TSO requirements based on IEC 61970/61968                                                                                                                           |
| Critical Branch / Critical Outages / Remedial Actions             | CBCORA  | File format for CRAC data, also known as Merged-CB or FlowBasedConstraint document                                                                                                                                           |
| Energy Identification Code                                        | EIC     | Standardized European code used to uniquely identify energy market participants, network elements, and areas                                                                                                                 |
| Mixed-Integer Linear Programming                                  | MILP    | Optimization problem in which some of the variables are constrained to be integers, while others are allowed to be non-integers. The objective function is linear with respect to the variables.                             |
| Mixed-Integer Programming                                         | MIP     | Mathematical optimization problem where some or all decision variables are constrained to be integers                                                                                                                        |
